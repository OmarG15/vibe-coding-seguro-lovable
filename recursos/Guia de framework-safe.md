# Framework SAFE

El framework SAFE organiza el desarrollo asistido por inteligencia artificial en cuatro etapas.

## S — Specify

Define claramente:

- Problema.
- Objetivo.
- Usuarios.
- Funcionalidades.
- Datos.
- Restricciones.
- Riesgos.
- Criterios de aceptación.

Antes de generar código debe existir una definición clara de lo que se espera construir.

## A — Assess

Evalúa el resultado generado:

- ¿Cumple los requisitos?
- ¿Agregó funciones no solicitadas?
- ¿Maneja errores?
- ¿Tiene validaciones?
- ¿Qué supuestos realizó?
- ¿Qué riesgos permanecen?
- ¿Qué elementos no pueden verificarse?

## F — Fortify

Fortalece la solución mediante:

- Validaciones del lado del servidor.
- Autenticación.
- Autorización.
- Mínimo privilegio.
- Protección de secretos.
- Pruebas.
- Revisión de dependencias.
- Manejo seguro de errores.
- Logs y auditoría cuando apliquen.

## E — Evolve

Mantén y mejora el sistema mediante:

- Control de versiones.
- Monitoreo.
- Actualizaciones.
- Backups.
- Gestión de vulnerabilidades.
- Retroalimentación.
- Métricas.
- Revisión continua.

## Resumen

> **Specify → Assess → Fortify → Evolve**

El prototipo es una entrada al proceso, no el final.
