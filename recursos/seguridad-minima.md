# Seguridad mínima para desarrollar con IA

## 1. Conoce al proveedor

Investiga:

- Quién desarrolla la herramienta.
- Por qué la elegiste.
- Cómo utiliza la información.
- Dónde procesa los datos.
- Qué funciones tiene según la forma de uso.

No es lo mismo utilizar:

- Una página web.
- Una aplicación de escritorio.
- Una extensión.
- Un editor con IA.
- Una herramienta CLI.
- Un agente con acceso al sistema.

## 2. Configura la privacidad

Revisa:

- Si las conversaciones o archivos se utilizan para mejorar modelos.
- Cuánto tiempo se conserva la información.
- Qué archivos o fragmentos se procesan.
- Qué configuraciones pueden desactivarse.
- Si la cuenta es personal o empresarial.

No compartas:

- Contraseñas.
- Tokens.
- Llaves de API.
- Archivos `.env`.
- Información de clientes.
- Datos personales.
- Código confidencial.
- Vulnerabilidades internas.

## 3. Limita los permisos

Comprueba si el agente puede:

- Leer archivos.
- Modificar código.
- Eliminar contenido.
- Ejecutar comandos.
- Instalar dependencias.
- Acceder a Internet.
- Leer variables de entorno.
- Conectarse a repositorios.

Aplica el principio de mínimo privilegio y exige aprobación para acciones sensibles.

## 4. Revisa todo tu entorno

Verifica:

- Extensiones instaladas.
- Autocompletado activo.
- Agentes conectados.
- Plugins.
- Cuentas iniciadas.
- Carpetas accesibles.
- Proveedores que procesan el código.

Configurar una herramienta no protege automáticamente la información procesada por otras extensiones.

## 5. Valida el resultado

Revisa:

- Archivos modificados.
- Dependencias agregadas.
- Validaciones.
- Permisos.
- Manejo de errores.
- Secretos expuestos.
- Acceso a datos.
- Resultados de pruebas.
- Riesgos pendientes.

> **La IA puede generar el código. Tú sigues siendo responsable de los datos, los permisos y el resultado.**
