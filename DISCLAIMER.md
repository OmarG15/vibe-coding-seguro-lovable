# Aviso de uso

Los materiales de este repositorio tienen fines educativos.

No constituyen:

- Una certificación de seguridad.
- Una garantía de cumplimiento normativo.
- Una autorización para probar sistemas de terceros.
- Un sustituto de revisión profesional.
- Software listo para producción.

Las demostraciones de seguridad deben realizarse únicamente en sistemas propios o expresamente autorizados, con datos ficticios y sin acciones destructivas.
