# Checklist de revisión funcional

Utiliza los estados:

- `Cumplido`
- `Parcial`
- `Incumplido`
- `No verificable`

| Área | Criterio | Estado | Evidencia / observaciones |
|---|---|---|---|
| Objetivo | Permite gestionar un inventario básico. |  |  |
| Dashboard | Muestra total de productos. |  |  |
| Dashboard | Muestra productos con inventario bajo. |  |  |
| Dashboard | Muestra el valor estimado del inventario. |  |  |
| Productos | Muestra nombre, categoría, SKU, precio, cantidad y nivel mínimo. |  |  |
| Registro | Permite registrar productos. |  |  |
| Edición | Permite editar productos. |  |  |
| Existencias | Permite aumentar o disminuir cantidades. |  |  |
| Búsqueda | Permite buscar por nombre, categoría o SKU. |  |  |
| Alertas | Identifica productos con inventario bajo. |  |  |
| Validación | Rechaza cantidades negativas. |  |  |
| Validación | Rechaza precios negativos. |  |  |
| Validación | Evita SKU duplicados. |  |  |
| Errores | Muestra mensajes claros. |  |  |
| Persistencia | Los datos permanecen después de recargar. |  |  |
| Diseño | La interfaz se adapta a dispositivos móviles. |  |  |
| Alcance | No agregó funciones fuera del alcance. |  |  |

## Preguntas para la revisión colectiva

- ¿Qué parte del resultado refleja mejor la especificación?
- ¿Qué requisito fue ignorado o interpretado de otra forma?
- ¿Cuál es el problema de mayor impacto?
- ¿Qué debe corregirse primero?
- ¿Cómo comprobaríamos que la corrección funciona?
